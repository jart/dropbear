# teddy algorithmic trading framework

teddy is a go framework for algorithmic trading.

It's inspired by QuantConnect in that it enables you to write a trading
algorithm in such a way that the same code is used for both backtesting
and live trading in production.

Unlike QuantConnect's Lean framework, teddy is designed to allow writing
trading programs that integrate with multiple exchanges, for either
arbitrage to leverage them for market intelligence.
